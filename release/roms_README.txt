Put your own WWF No Mercy ROM in this folder.

It must be the USA release, Rev 1: "WWF No Mercy (USA) (Rev 1)", a .z64, .n64 or .v64 file, or a
.zip holding one (SHA-1 of the .z64: 91CEE3D096F4A76644D8B35B9AEAD6448909ABD1). The original USA
release (Rev 0, "v1.0") is not accepted as the main ROM. The game checks the file when it starts
and keeps a copy of it beside the program (wwf.nomercy.us.z64).

Optional: your other games, in this folder too. Each adds Superstars, moves, arenas or themes,
made from it on the next start (the game knows a ROM by its contents, not by its file name):
  - WCW/nWo Revenge (USA)
  - WWF WrestleMania 2000 (USA)
  - WWF No Mercy (USA) v1.0 together with the patch "No Mercy Plus V3.xdelta": No Mercy Plus V3
  - the WCW/nWo Revenge Redux patch (its release .zip or its .xdelta), with WCW/nWo Revenge
  - WWF WarZone - Badd Blood (USA) (v1.0), with WWF WrestleMania 2000
  - WWE '13 (USA) for the Wii as an .rvz disc image: the commentary (README.txt, "commentary")
Keep them here: a ROM taken out is left out at the next start (wrestler folders made from it stay).

Nothing from any game is included in this download: you must own the games.
