TEXTURE PACKS

A pack is a folder in here, full of PNG files, each replacing one picture the game draws. They can be any size.

To get the pictures to edit:
  1. Make a folder here called _dump.
  2. Play. The game saves every new picture it draws into _dump, named by a number made from its contents.
  3. Delete _dump when you're done: saving slows the game a little.

Edit the ones you want, keep their names, and move them into your pack's folder.

Packs load in folder-name order, and a later pack wins if two have the same picture. Put an underscore at the start of a
pack's name to turn it off. The game's log lists what it found: look for lines starting [textures].

Pictures that change every frame, like Titantron videos, can't be replaced this way, because each frame is a new picture.
The first time a large replacement is used the game can hitch for a moment while it loads.
